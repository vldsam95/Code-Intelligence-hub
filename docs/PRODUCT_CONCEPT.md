# Product concept

The goal is to reduce defects and provide justified confidence while using context efficiently. Priorities are correct source identity, avoiding false confidence, review and verification quality, provenance and freshness, followed by convenience and token savings.

```text
actual source = truth
graph = derived discovery evidence
tests and checks = validation evidence
runtime = observed behavior under a declared workload
wiki = optional durable knowledge
```

The product is not a sandbox, deployment system or VPS snapshot manager. Agents continue using their normal shell and editing tools.
