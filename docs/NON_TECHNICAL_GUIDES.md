# Practical guides for project owners

The Hub's **Guides** page provides a visual workflow and a complete prompt for each action:

1. Install a Worker on a new host.
2. Explicitly enable a new project.
3. Work on an existing codebase.
4. Move a project between servers.
5. Optionally connect an LLM Wiki.
6. Connect a remote agent for reading or presentations only.

The prompts are maintained in `SIMPLE_GUIDE_*.md`, available as rendered pages and raw Markdown, and included in the release's documentation ZIP.
