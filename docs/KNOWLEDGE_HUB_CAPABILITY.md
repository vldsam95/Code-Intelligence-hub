# Knowledge Hub Conditional Capability

This Wiki is linked to a Code Intelligence project.

Use the Wiki for durable project knowledge, business and technical rationale, decisions, invariants, operational context, and validated long-term conclusions.

Use Code Intelligence and the actual current source for live code structure, callers, dependencies, impact, review, tests, runtime observations, data-flow, and current code-quality evidence.

The central Context Pack may answer status, history, architecture summaries, known risks and last-known health without storing full source. If an exact current technical answer is needed and an active Worker is available, request live analysis.

Do not treat a derived graph as canonical truth. Do not infer absence from an empty graph result. Do not copy raw graph dumps or volatile caller lists into canonical Wiki pages.
